# JSM Evolved 0.7.155 — unsigned prerelease

Windows x64 · early testing release · 20 October 2026.

[Download the Windows installer](https://github.com/LukeyBeachBoy/JSM_Studio/releases/tag/v0.7.155).
This prerelease contains the interface and permission changes shown in the README.
It is not a completed clean-machine or hardware acceptance test. Back up your
configuration library before upgrading.

## Changes

- Normal launch uses ordinary Windows access. Administrator restart remains an
  explicit action, with a separate optional preference for manual launches.
- **Windows sign-in input is now off by default.** Enable it through Settings →
  Startup → Windows sign-in and confirm the explanation. An existing FakerInput
  installation or sign-in preset does not grant consent.
- Disabling sign-in cancels pending sign-in actions. Re-enabling ignores held
  buttons until release. Reset everything also revokes consent. Ordinary mappings
  are suppressed on the locked desktop even when sign-in is off.
- **View release opens GitHub in your browser.** All Tauri update entry points,
  including the legacy bridge, leave installation to the user. The app no longer
  downloads or launches an update installer.
- Mode shifts use the shared pad/stick/trigger editors. Mouse-area selection and
  inherited settings preserve their intended scope.
- Live-profile indicators distinguish the active mapping from the profile being
  edited. Controller-driven profile changes update the editor and overlays.
- Setup documentation now explains driver choices, permissions, Windows sign-in,
  update behavior, project lineage and compatibility limits.

## Before a broad Reddit launch

The matching source is published and CI builds the unsigned prerelease. These
manual checks remain open on the exact public installer:

1. Clean-machine install, driver refusal/approval, native UAC acceptance and
   cancellation, startup migration, and independent uninstall/profile-retention
   testing. The maintainer-PC upgrade and isolated first-run checks passed.
2. Physical-controller/game and lock-screen testing. Record the controller model,
   firmware, transport, Windows version and game. List Steam Controller 2015 and
   2026 separately. Keep a physical keyboard available; do not record a real PIN
   or input telemetry during sign-in.
3. Outside setup feedback and a short real-controller demonstration. Present this
   as a request for early testing rather than a broadly validated release.

Signing remains future work. This prerelease explicitly ships unsigned.

## Known limits

- Windows x64 only; no Linux/SteamOS/macOS desktop package.
- Controller support in code is broader than the hardware tested for this
  candidate. Steam Controller 2015 and 2026 must be listed separately.
- Virtual gamepad output depends on ViGEmBus, which is retired upstream. FakerInput
  and HidHide are optional shared drivers with separate installation/recovery.
- Windows sign-in input supports an already-running user's locked session, not
  the first Windows login after a reboot.
- No universal anti-cheat compatibility, mixed mouse/gamepad support or latency
  advantage is claimed.

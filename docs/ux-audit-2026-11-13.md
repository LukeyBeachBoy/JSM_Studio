# November 2026 UX audit remediation

Source: `JSM Evolved UX Audit.zip`, supplied on 13 November 2026. Its 48 detailed findings, ten priorities and improvement ideas were reviewed against the current working tree. Existing unrelated local changes were preserved. The document is reference material; repository instructions and the user's request govern implementation.

## Improvement ideas implemented

- Ctrl+K opens navigation/configuration search; Ctrl+Shift+F starts global Find a button.
- Layout edits in place; copy/paste actions are visible from binding rows.
- Visible Save and shortcuts, compact layer/source toolbar, two primary trigger choices, disabled reasons and mapper/error recovery.
- Three-step welcome, illustrated compact wizard choices and consistent layer/menu/live vocabulary.

The searchable binding catalogue remains scoped to editing a binding: choosing an output globally without a target input would not have a meaningful write destination. Ctrl+K indexes pages, settings and configurations, while the catalogue indexes outputs.

## Follow-up corrections from native-app screenshots

The initial browser audit did not render native window controls or combine all controller/live-profile header states. Subsequent screenshots exposed wrapping and text containment regressions. The header now has an explicit primary row and tab row, with a reserved native-button area. Window controls are also retained on full-screen subpages. Executable game icons take precedence over the deterministic fallback again.

`tests/frameless_header_browser_regression.cjs` renders the production header components with mocked native actions at 1452, 1280, 1100 and 900 px, across saved, unsaved, other-live-profile, Home and Library states. It checks button anchoring, row bounds, icon loading, text containment and minimise/maximise/close routing, plus subpage chrome. The 92-combination integrated browser regression and production build pass after these corrections.

The RWS caption now defines the camera/controller rotation ratio without treating a curve-form configuration as proof of acceleration. Equal and reversed endpoint regressions cover flat and decreasing sensitivity. Calibration headings use paired font-size/line-height tokens and explicit paragraph spacing; 1280 px and 900 px rendered checks confirm wrapping without overlap.

Controller polling no longer lives under Gyro → Direction → Advanced. Settings → Controller exposes the shared polling default before its topic navigation, identifies it as the mapper read interval, and links directly to the existing Buttons → Configuration timing override. Existing profile values are preserved. Polling history/inventory links now route to configuration timing, and gyro routing excludes `TICK_TIME`. `controller_polling_browser_regression.cjs` verifies visibility, shared persistence and isolation from profile overrides at normal/minimum sizes in both themes.

Changed:

- `ActionPicker.tsx` (+ `.css`) is now **"Search every action"** and the picker nested editors use (`allowedOutputKinds`: `CycleBindingFields`, `VirtualMenuActionEditor`, BIND's cycle step). Families are named and ordered as the eight kinds (Keyboard key · Mouse · Gamepad button · Open a menu · Switch mode · Controller action · Load a config · Command); Controller action has the five groups; Command is the compact typed form (Command | Raw binding; Haptic left for Controller action). `startWithSearch` opens with the search box focused; X is "Listen for a key"; unavailable choices are `aria-disabled` + `data-reason`; `title=` is gone (`data-caption`); glyphs follow the pad's family; `onEnableVirtualController(type?)`, `onAddStickShift(stick?, mode?)`, `onAddLayerAction(layerId, verb?, onRelease?)` and `onSelectCombo` widen the old callbacks compatibly.
- `jsmActionGroups.ts`: now the five Controller-action groups and their tokens (`CONTROLLER_ACTION_GROUPS`, `jsmActionGroupFor`, `jsmActionIcon`).
- `IconPicker.tsx` (+ `.module.css`): `IconPicker` (the "Change icon" button; props unchanged, plus optional `item`/`menuName`) opens **`IconPickerPage`**, a full-screen `PickerPage` "Pick an icon", eyebrow "<menu> · <item>", categories on LT/RT, labelled tiles ("Wooden crate"), "Thousands of game icons · showing the first N", "Show 160 more ▾", aside **On the menu** (the real `MenuPreview` of the item's menu, found from `item` or the label, with the focused icon in the item's slot), the focused icon's large name, "Shown above "Supply crate" on the menu", the **Now** card with X No icon, and the Custom note. Y searches. The old "+ Import" button is gone (the design has none).
- `TextEntryOverlay.tsx` (+ `.module.css`) and `nav/textEntry.ts`: the design's TextEntry. Context header (glyph from `input`, title, eyebrow, "A real keyboard types here too"), the field with its hint, **Suggestions** ("Move up to choose one"), the exact layout (`1234567890-` / `qwertyuiop'` / `asdfghjkl,.` / Shift z…m &123 / Caps Backspace Space Enter Done), the live hint "A types p · hold LT for a capital · L3 locks caps", the footer naming every button. **LT** Shift (hold for a capital, a tap is one-shot), **RT** Enter (new line in a textarea, else Done), **L3** Caps lock, **LB** &123 (RB no longer toggles symbols), **X** Backspace, **Y** Space, **Menu** Done, **B** cancel; **hold R3 + D-pad** moves the window, **hold RB + D-pad** resizes it, **LB + RB** reset (the frame is remembered in `localStorage`). The request API is unchanged and compatible; `TextEntryRequest` gained optional `input` and `where`.
- `nav/useControllerNavigation.ts` (small, additive): while an overlay is open it announces the held buttons (`jsm:pad-held`, `PAD_HELD_EVENT` in `nav/textEntry.ts`), which is how the keyboard reads LT held, L3, R3, RB.
- `hooks/useKeyboardNav.ts` (one selector): an `aria-disabled` control that carries `data-reason` stays reachable by the pad (the Kit's rule "unavailable stays focusable and says why"; nothing else used `[aria-disabled]` for this before).
- `dev/PickerPlayground.tsx` (new, dev only; mounted in `App.tsx` beside the kit playground): open any picker from the console, `window.dispatchEvent(new CustomEvent('jsm:picker', { detail: { kind: 'controller', input: 'S', value: '', trigger: 'regular' } }))` (kinds: key mouse gamepad menu mode controller config command nested) or `jsm:icon-picker` with `{ menu, item, value }`. What a picker hands back lands in `window.__pickerResult`.
- i18n: a `pickers.*` block in `en.ts` and `zh-CN.ts` (and `pickers.modeChanges_one/_other`); the old `keymap.picker*`/`custom*`/`icon*` keys that changed words now live there.

## Not done / handed on, and why

- **Verifying the lower halves of some shared tests.** `light_bar_picker` (its first half asserts the old Preferences page), `additional_configuration` (row "Command settings" sheets), `feedback_binding_polish` (the row's `keycapKey`), `usability_audit` / `shifted_binding_imports` / `steam_workspace` (profile chip, "Modeshift settings", Desktop chip), `template_override_roundtrip` (gyro page inputs), `parity_controls` (the cycle editor's old rows, which BIND's Fine-tune replaced) and `gyro_action` (Trigger combobox, Command settings) fail **before** they reach a picker, on screens other areas redesigned. I changed their picker steps and ran those steps in isolation where I could (`light_bar` card section, `additional_configuration` picker section: both pass), but the whole files need their owners' halves updated.
- **Key combo replacing a key** (BIND): choosing a combo while a key is set writes `N = SPACE\ LCONTROL\ LSHIFT\ SPACE\`; the old key stays (`addCommand`'s `replace` removes it from `rows`, then writes from the stale `baseRow`). My side hands over `onSelectCombo(['LCONTROL','LSHIFT','SPACE'])` correctly.
- **Controller-scoped layer actions** (not mine): with a controller connected, `setLayerActions` through `setControllerDocument` wrote `# @controller type-24 # @layer-action !N = toggle aim`, and the sheet did not list it afterwards. Both Switch mode paths (BIND's `addLayerAction` and mine) go through the same `onSetActions`; `command_parameters` accepts the prefix.
- **Rename header glyph:** `TextEntryRequest.input` draws the input's glyph; BIND's `renameInput` and the others do not pass it yet (the title and eyebrow already show).
- **Hardware:** X "Hear it" calls `playControllerSound`, which only makes sound in the Tauri app; the mock can't hear it. R3 / RB window move and resize use the pad's telemetry; checked with the mock pad only.
- **Cover art for Steam library games** (D23) is LIBRARY's service; until it lands the shelf shows the association's app icon or a flat generated cover.

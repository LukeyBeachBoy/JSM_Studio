TURN 4 · NATIVE CONTROLLER NAVIGATION
Studio has the controller; Test hands it back
While Studio's window has focus it reads the pad through SDL and the applied profile pauses; global chords still fire when held. Test runs the profile inside Studio until you hold View + Menu, press Esc or click Return. The live preview keeps drawing pad touches, trigger pulls, stick positions and grip contact in every mode, because telemetry is its own stream.

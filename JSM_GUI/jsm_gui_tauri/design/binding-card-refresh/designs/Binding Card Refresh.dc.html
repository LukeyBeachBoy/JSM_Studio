RULES
Every row starts with the input, drawn as glyphs: A, or L4 + A. L4 is a white rounded cap, the same art as the capsule.
Outputs are tiles: keycaps for keys and mouse, rounded colour tiles for layers (“Hold Vehicles”).
Activation is a coloured chip-select (PRESS / HOLD / DOUBLE…), not a grey dropdown, so it reads as part of the combo.
One cog per row opens that row’s settings sheet (output mode, rename, duplicate, copy, remove). Header cog holds card-level Copy / Paste / Reset. No ··· and no text-only buttons anywhere.
Add buttons are console buttons: filled, bordered, 44px, bottom bevel, with a solid “+” cap in the lane colour. Capture sits beside Add with its real X glyph.
Empty lanes show only their header and Add button.

WHAT CHANGED FROM THE CURRENT CARD
Icon + label promoted. They describe the menu slot, not a command, so they move out of the command row. A on the icon opens the icon modal (1g).
Output is one pill. “Output: Keyboard” dropdown, value field, Capture and Keyboard… collapse into the output pill; A opens the picker, which already has Capture and every category.
Options is an icon. Options / ··· / Remove become one tuning button; Remove lives at the bottom of the open options.
No nested boxes. Options is a flat list with hairlines inside the command well, so borders never double up or clip at the edge.
Copy / Paste go under ··· on the header, same as binding cards.
1fChoose an action · System & media category
Volume, mute, media and Print Screen are outputs like any other, so they become a picker category. Nothing about them stays in Advanced.

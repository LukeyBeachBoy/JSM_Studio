Tuning moves next to what it tunes. Home splits this configuration from all configurations.
"Tuning" is no longer a category. Grip sensors become a summary row on Buttons › Grips, and trackpad tuning becomes Mouse feel, a row under any pad set to Mouse. Both open as sheets. Home shows them inside the Wardogs card as shortcuts, so it's clear they're saved in Wardogs. Press timing & polling and the AI assistant move to Studio with the other global tools. The Menu layout page is removed: every pad or stick menu gets an On-screen menu row that opens the arrange view with all of this configuration's menus.
Every hint uses the controller's own button art, so you can look down and find it. Home from anywhere (Up still reaches the title bar) · Configuration menu (1e) · page · section.

TURN 1 · CONSOLE REFINEMENT
Fewer, larger targets. Tuning and Studio get names.
Three ways to make Tuning and Studio first-class destinations, all shown on Gyro. Shared across all three: one focus target per row, with value on the right and detail in a sheet. Secondary actions move off the row onto face buttons, listed in the hint capsule. Undo, Save and Apply fold into one state button plus the ☰ Configuration menu. Every page shows its essentials first, and the rest sits behind summary rows.
1aThree hubs in the title bar
Configure, Tuning and Studio sit side by side as large labelled segments. The tab strip below changes with the hub, and LT/RT walk the pages inside it. View selects the hub switcher from anywhere, and the logo is decoration only.
